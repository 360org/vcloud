BIỂU ĐỒ TRÌNH TỰ THỜI GIAN (UML SEQUENCE DIAGRAM)

Tương tác 18 bước: Admin Khách hàng ➔ Odoo Web DB ➔ Hook Daemon Thread ➔ Master Hub (vuahethong.net) ➔ Mobile App

1 Giai đoạn 1: Cấp phát tại DB Khách

Admin tạo User trên Odoo Web của công ty mình. PostgreSQL lưu dữ liệu và commit an toàn 100%. Giao diện Web phản hồi ngay lập tức (0ms delay).

2 Giai đoạn 2: Bắn Webhook Ngầm (Daemon)

Luồng nền threading.Thread(daemon=True) bắn Webhook lên Master Hub. Master chỉ lưu (login, project_id), tuyệt đối KHÔNG lưu mật khẩu.

3 Giai đoạn 3: Người Dùng Đăng Nhập

Người dùng mở App chỉ nhập Email & Password. Master Hub tra danh bạ điều hướng App kết nối thẳng vào DB khách hàng để đăng nhập (Zero-Config).
